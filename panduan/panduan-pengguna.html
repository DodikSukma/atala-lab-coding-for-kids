Panduan Atala Lab

Petunjuk singkat untuk pemilik, guru, dan pendamping belajar.

Mulai untuk siswa

1Buka aplikasi Atala Lab. Pilih tema Angkasa atau Taman di bagian atas. Tema pilihan tersimpan di browser.

2Pilih kartu Bulan 1 atau Bulan 2. Empat kartu bulan berikutnya bertanda Segera hadir.

3Buka pertemuan sesuai urutan. Baca bagian Kenali, Coba, dan Tantangan.

4Di Lab Interaktif, seret blok dari kolom kiri ke susunan program dengan mouse atau sentuh. Seret blok yang sudah ada untuk mengubah urutan. Tombol tambah dan panah tetap bisa dipakai. Ikon tempat sampah menghapus blok. Blok Ulangi dan Jika sentuh bintang berlaku untuk satu blok tepat di bawahnya.

5Tekan Jalankan untuk melihat tokoh bergerak. Tekan Hentikan atau Ulang awal untuk mencoba lagi.

6Isi nama proyek, lalu tekan Unduh karya HTML. File tunggal itu dapat dibuka dengan klik ganda di browser tanpa internet: animasi akan berjalan, atau tekan Tombol aksi untuk game. Tekan Simpan proyek agar bisa dilanjutkan di perangkat ini. Gunakan Cadangan JSON bila ingin mengimpor kembali ke Atala Lab.

Uji file hasil unduhan: buka folder Unduhan, klik ganda file atala-karya-....html, lalu pastikan browser menampilkan judul karya dan tokoh di panggung. Untuk animasi, tokoh mulai bergerak sendiri; untuk game bertombol, tekan Tombol aksi. Coba Ulang dari awal dan Jalankan bila tersedia. Alamat browser seharusnya menunjukkan file lokal, bukan localhost. Ulangi saat internet mati bila ingin memastikan karya benar-benar mandiri.

Untuk guru atau pendamping

  • Setiap bulan aktif memiliki empat pertemuan dan satu proyek akhir. Kerjakan satu pertemuan dalam satu sesi bila sesuai dengan kelas.
  • Mintalah siswa mengikuti langkah Susun blok → Jalankan → Simpan karya, membuka Butuh petunjuk? bila perlu, dan menjelaskan pilihannya pada bagian Ceritakan.
  • Untuk melihat hasil yang langsung dimainkan, minta siswa menyerahkan file HTML. Untuk cadangan yang dapat diedit lagi, minta file JSON. Keduanya dapat diunduh dari halaman Proyek Saya.
  • Proyek lokal hanya ada di browser perangkat itu. Jangan menghapus data browser sebelum mengunduh cadangan.
  • Buka Papan Guru untuk menggambar penjelasan. Pilih Pena, Kotak, Lingkaran, Panah, atau Teks. Seret dari titik awal ke akhir untuk menggambar panah ke arah mana pun. Salin screenshot lalu tekan Tempel gambar atau Cmd/Ctrl+V; pilih gambar untuk menyeretnya atau tarik pegangan sudutnya untuk mengubah ukuran. Dengan alat Teks, klik tepat di bagian papan yang diinginkan, ketik, lalu tekan Enter. Klik dua kali teks untuk mengubahnya. Pilih objek lalu tekan Hapus pilihan bila perlu.
  • Tekan Tambah halaman A4 di bawah papan untuk melanjutkan catatan ke bawah. Gulir halaman untuk melihat seluruh isi. Tekan Simpan agar semua halaman tersimpan di browser ini; tekan Unduh PDF untuk mendapatkan seluruh halaman dalam satu file.

Menjalankan aplikasi oleh pemilik

  1. Pasang Node.js versi 20.9 atau lebih baru dan Make.
  2. Di Visual Studio Code, pilih File → Open Folder, lalu buka folder akar atala-lab-coding-for-kids. Buka Terminal → New Terminal.
  3. Jalankan make setup sekali, lalu make dev. Terminal kembali siap dipakai karena web dan API berjalan di latar belakang. Buka http://localhost:3000 untuk aplikasi dan http://localhost:4000/health untuk status API.
  4. Jalankan make status untuk memeriksa layanan, make stop untuk menghentikan keduanya, atau make restart untuk menjalankan ulang. Untuk mode produksi lokal, gunakan make start setelah make stop; perintah itu membangun dan menjalankan kedua layanan di latar belakang.
  5. Untuk sinkronisasi, buat proyek Supabase, aktifkan Anonymous Sign-ins, jalankan apps/api/supabase/001_projects.sql, lalu isi contoh env pada apps/web/.env.example dan apps/api/.env.example. Baca README untuk rinciannya.

Tanpa Supabase, latihan dan simpan lokal tetap berfungsi. Log web dan API ada di .local-dev/web.log dan .local-dev/api.log. Jika port sudah dipakai program lain, hentikan program itu sendiri sebelum mencoba lagi. Sinkronisasi tidak boleh dianggap aktif sebelum health API menunjukkan konfigurasi dan penyimpanan nyata berhasil diuji.

Jika ada kendala

  • Blok tidak berjalan: pastikan ada blok “Ketika mulai” dan tekan Jalankan.
  • Skor tidak berubah: gerakkan tokoh ke bintang lalu letakkan “Jika sentuh bintang” tepat sebelum “Tambah skor”.
  • Proyek tidak terlihat: periksa browser dan perangkat yang dipakai, atau impor file JSON cadangan.
  • Sinkronisasi gagal: proyek tetap tersimpan lokal; periksa API, env, Anonymous Sign-ins, dan migrasi Supabase.
