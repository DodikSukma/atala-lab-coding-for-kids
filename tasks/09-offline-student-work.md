# 09 — Karya siswa mandiri dan alat papan guru

- [x] Ekspor satu file HTML tanpa ketergantungan eksternal untuk animasi/game Bulan 1–2.
- [x] Runtime tertanam untuk gerak, putar, ucap, jeda, pengulangan, kondisi bintang, dan skor, dengan batas 80 blok/500 langkah.
- [x] Pilihan latar dan tokoh, judul, program, kontrol mulai/aksi/reset, serta pengamanan teks siswa.
- [x] Tombol ekspor di Studio dan Proyek Saya, terpisah dari cadangan JSON.
- [x] Langkah belajar, tantangan, dan petunjuk singkat pada Studio.
- [x] Tempel gambar clipboard dan panah arah bebas di Papan Guru; simpan, ubah ukuran/posisi, riwayat, dan PDF.
- [x] Uji unit runtime tertanam terhadap runtime editor; uji browser tempel, geser, ubah ukuran, simpan/buka, ekspor PDF.
- [x] Audit berkas HTML hasil unduhan: satu script dan style tertanam, tanpa rujukan aset, URL jaringan, fetch, modul, atau penyimpanan browser. Salinan identik byte dijalankan melalui server lokal: animasi otomatis, reset, replay, dan pencapaian target bekerja tanpa kesalahan browser. Game bertombol juga diuji di browser: menunggu klik, menambah skor, lalu mengaktifkan lagi tombol aksi.
- [ ] Verifikasi klik ganda `file://` pada perangkat pengguna; browser otomatis di lingkungan ini menolak protokol lokal.
